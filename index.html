01 / 09

Pipeline flow

Five stages, fully offline up to the staging step. Re-runnable via the /outreach-batch skill on any future CSV.

  1. 01 · INPUT
    CSV + CRM dump
    Apollo export (9k rows) + official Zoho backup (20k Leads, full schema, picklists, users).
  2. 02 · DEDUP
    Email · phone · name+company
    Match Apollo rows against CRM Leads. Three-key matching with case + whitespace normalization.
  3. 03 · CATEGORIZE
    Ready · Clay · Reject
    Filter by data sufficiency. Send Clay-enrichable rows to a queue rather than dropping them.
  4. 04 · DRAFT
    CONTEXT.docx · pilot first
    Per-row email using only verified facts. 10-row pilot, reviewed by partner before bulk.
  5. 05 · STAGE
    Apollo Sequences
    Upload in batches respecting per-mailbox daily caps. Never auto-send. Monitor reply/bounce.
RULE 01
Claude first, Clay only when uniquely needed
Most rows already have Title, Company, Industry, and LinkedIn URL. Don't pay Clay credits to find what's already in the CSV.
RULE 02
Filter insufficient-data rows out
Rows missing the core inputs for a personalized email skip the draft pass and queue for Clay enrichment instead.
RULE 03
No fabrication
Only verifiable USAIndiaCFO claims. The "12,000 companies" stat is omitted — not on the live site.

What's slow, and why
  • 14–21d Sending pace. 5 mailboxes × ~80–150/day at warmup-safe rates. Going faster trashes domain reputation; can't be parallelized further without buying more domains and warming them.
  • 1–3d Partner + marketing review. Calendar-bound; the only way to compress is to get sign-off attention earlier. Pre-share a Loom walkthrough alongside the pilot to cut cycles.
  • 3–6h Clay enrichment. Async waterfall on 4,602 rows. Can run overnight in parallel with sending the Ready cohort — doesn't block.
What's already fast
  • ~30s Dedup vs CRM. 9k Apollo × 20k Zoho indexed + matched in stdlib Python.
  • ~30s Zoho analyze. Full fill-rate, distributions, hygiene, Flow A/B/C bucketing.
  • ~10s Categorize. Filter 8,277 rows into Ready / Clay / Reject by data sufficiency.
  • ~30m Bulk draft (template-mode). 3,646 ready rows from CSV + cached facts; deterministic conditional fill.

Send pacing reality

5 mailboxes × ~100/day = 500 sends/day

Drafting all 3,646 ready rows is fast; sending them isn't. At a warmup-safe send rate the ready cohort alone is 8–10 days of throughput. The 4,602 Clay-enriched additions extend that to 5–7 weeks. Plan in tranches; monitor reply / bounce rate after the first 200 sends.
